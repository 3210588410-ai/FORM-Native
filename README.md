# FORM V1 — iPhone 个人健身与饮食管理

## 已实现
- 深色高级风格、五个主导航页面
- 碳水/蛋白质/脂肪每日固定目标：160g / 130g / 55g
- 自动按 4/4/9 计算热量：**1635 kcal**（按上述三项宏量营养素精确计算）
- 饮食记录：手动录入克数、每100g营养值、餐次、自动累计
- 食物快捷库：内置常见食物，可保存自定义食物
- 训练记录：日期、部位、动作/组数/次数/重量、有氧备注
- 身体数据：体重、体脂率及最近7次体重趋势
- JSON 完整备份/恢复、饮食 CSV 导出
- 本地浏览器存储；PWA service worker 离线缓存

## 尚未接入的能力
- AI 照片识别：当前可选择照片作为辅助，但没有接入 AI 视觉 API；需要后续配置安全的服务端 API，不能把密钥写进前端。
- iCloud 同步：本版本没有云同步；可通过定期导出 JSON 备份。
- App Store 原生安装：这是可添加到主屏幕的 PWA 原型，不是已签名的原生 iOS 安装包。

## 在 iPhone 上运行
1. 将 FORM 文件夹部署到 HTTPS 静态网站托管服务（例如你自己的域名/静态托管）。
2. 用 iPhone Safari 打开部署网址。
3. 点击分享按钮 →「添加到主屏幕」。
4. 从主屏幕打开 FORM。

本地直接双击 HTML 可用于预览，但 PWA 离线缓存和安装能力需要 HTTPS 或 localhost。
数据默认保存在当前 Safari 网站数据中。清理网站数据或卸载相关数据前，请先导出备份。
